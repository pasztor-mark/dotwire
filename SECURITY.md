# Security Policy

## Supported versions

Security fixes go into the latest release only. Upgrade to it before reporting; see [UPGRADING.md](UPGRADING.md).

## Reporting a vulnerability

Do not open a public issue for a security problem.

Report it privately through GitHub: on the repository's **Security** tab, choose **Report a vulnerability**. Include the affected version, the steps to reproduce it, and the impact you expect.

You will get an acknowledgement on the report. Once a fix is released, the advisory is published with credit to the reporter unless you ask otherwise.
